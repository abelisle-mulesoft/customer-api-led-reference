## Support

If you need assistance using the Salesforce Brilliant Mule Customer Events Integration, contact the integration platform support team at [support@brilliantmule.com](mailto:support@brilliantmule.com).

Support hours are Monday through Friday from 9:00 AM to 5:00 PM Pacific Time.

The target response time for support inquiries is within four business hours.

## Before Requesting Support

Before submitting a support request, please review the following resources:

- The documentation pages of this asset.
- The Salesforce Brilliant Mule Customer System API documentation.
- The Canonical Customer Types Library.
- The Customer Process API documentation.

These resources provide information about the integration's purpose, Salesforce account retrieval, canonical data mapping, and downstream processing.

## Information to Include

When submitting a support request, please include the following information:

- Exchange asset name and version.
- Description of the issue or question.
- Relevant error messages or logs.
- A sample CDC event payload, when available and appropriate.

## Intended Usage

The Salesforce Brilliant Mule Customer Events integration processes changes to account data originating from the Salesforce Brilliant Mule instance via Change Data Capture (CDC) events. Support requests should be related to:

- CDC event reception or connectivity issues.
- Errors processing or transforming incoming CDC events.
- Issues delivering canonical customer data to the Customer Process API.
- Questions regarding supported Salesforce account structures and canonical data mapping.
