## Support

If you need assistance using the SAP ECC Customer Events Integration, contact the integration platform support team at [support@brilliantmule.com](mailto:support@brilliantmule.com).

Support hours are Monday through Friday from 9:00 AM to 5:00 PM Pacific Time.

The target response time for support inquiries is within four business hours.

## Before Requesting Support

Before submitting a support request, please review the following resources:

- The documentation pages of this asset.
- The Canonical Customer Types Library.
- The Customer Process API documentation.

These resources provide information about the integration’s purpose, data transformation, and downstream processing.

## Information to Include

When submitting a support request, please include the following information:

- Exchange asset name and version.
- Description of the issue or question.
- Relevant error messages or logs.
- SAP IDoc type and message identifier, when applicable.
- A sample IDoc payload, when available and appropriate.

## Intended Usage

The SAP ECC Customer Events integration processes customer master data changes originating from SAP ECC through DEBMAS07 IDocs. Support requests should be related to:

- SAP IDoc reception or connectivity issues.
- Errors processing or transforming incoming IDocs.
- Issues delivering canonical customer data to the Customer Process API.
- Questions regarding supported IDoc structures and canonical data mapping.

## Contribution and Feedback

Feedback and improvement suggestions are encouraged to enhance clarity, interoperability, consistency, and reuse across integrations. Proposed changes should align with existing platform standards and design principles. If you identify documentation gaps or opportunities to improve data transformation or integration behavior, submit feedback through your integration architecture or platform enablement team.
